ZEDEDA Marketplace — Inbound & Outbound MCP Functions
This marketplace implements the Model Context Protocol (MCP) as both a server (exposing 7 tools to AI agents) and a client (calling Anthropic, NVD, and Jira). Any MCP-compatible AI — Claude Desktop, Claude Code, or a custom orchestrator — can connect and query the catalog, get recommendations, or report issues. CVE security status is queried live from NVD on demand and surfaced directly on every device widget as a colour-coded badge — no separate tooling required.
